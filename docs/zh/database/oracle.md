# Oracle 基础语法和技巧

Oracle 常用于企业级业务系统，对事务、权限、稳定性和复杂 SQL 支持较强。

## 创建表

```sql
CREATE TABLE users (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username VARCHAR2(50) NOT NULL UNIQUE,
    email VARCHAR2(100),
    status VARCHAR2(20) DEFAULT 'ACTIVE' NOT NULL,
    created_at DATE DEFAULT SYSDATE NOT NULL
);
```

## 增删改查

```sql
INSERT INTO users (username, email)
VALUES ('zhangsan', 'zhangsan@example.com');

SELECT id, username, email
FROM users
WHERE status = 'ACTIVE'
ORDER BY created_at DESC
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY;

UPDATE users
SET email = 'new@example.com'
WHERE id = 1;

DELETE FROM users
WHERE id = 1;
```

## 常用函数

| 类型 | 函数 | 示例 |
|------|------|------|
| 字符串 | `||` | `first_name || last_name` |
| 字符串 | `LENGTH` | `LENGTH(username)` |
| 日期 | `SYSDATE` | `SYSDATE` |
| 日期 | `TO_CHAR` | `TO_CHAR(created_at, 'YYYY-MM-DD')` |
| 空值 | `NVL` | `NVL(email, '未填写')` |
| 条件 | `CASE` | `CASE WHEN status = 'ACTIVE' THEN '启用' ELSE '停用' END` |

## 序列用法

旧项目中常见序列加触发器或手动取序列值。

```sql
CREATE SEQUENCE user_seq START WITH 1 INCREMENT BY 1;

INSERT INTO users (id, username)
VALUES (user_seq.NEXTVAL, 'lisi');
```

新版本也可以使用 Identity 列简化自增主键。

## 事务

```sql
UPDATE accounts SET balance = balance - 100 WHERE id = 1;
UPDATE accounts SET balance = balance + 100 WHERE id = 2;

COMMIT;
-- 出错时使用 ROLLBACK;
```

Oracle 默认不会自动提交普通 DML，需要明确 `COMMIT` 或 `ROLLBACK`，具体也会受客户端工具设置影响。

## 小技巧

- 使用 `VARCHAR2` 而不是 `VARCHAR`。
- 日期格式展示用 `TO_CHAR`，日期比较尽量使用日期类型本身。
- 大批量查询前先看执行计划，关注是否全表扫描。
- `ROWNUM` 在排序前生成，分页排序时优先使用 `OFFSET ... FETCH` 或子查询。
- 避免在索引列上直接套函数，否则可能影响索引使用。
