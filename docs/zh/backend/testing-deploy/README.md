# 测试和部署

后端服务需要经过测试、构建、配置、部署和监控，才能稳定运行在生产环境。

## 测试目标

- 核心业务逻辑可验证。
- 数据访问行为正确。
- 接口输入输出稳定。
- 修改代码后能快速发现回归。

## 部署目标

- 环境配置清楚。
- 构建过程可重复。
- 服务可健康检查。
- 日志可查看。
- 出问题可以回滚。

## 常见环境

```text
local       本地开发
dev         开发联调
test        测试环境
staging     预发布
production 生产环境
```

不同环境应使用不同配置，密钥不能写死在代码里。
