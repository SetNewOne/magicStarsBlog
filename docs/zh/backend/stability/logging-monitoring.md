# 日志和监控

日志用于定位单次请求，监控用于观察系统整体状态。

## 日志内容

建议记录：

- traceId。
- 请求路径和方法。
- 用户 ID 或租户 ID。
- 关键业务参数。
- 耗时。
- 错误堆栈。

不要记录：

- 明文密码。
- 完整 token。
- 身份证、银行卡等敏感信息。

## 日志级别

| 级别 | 用途 |
|------|------|
| DEBUG | 开发调试 |
| INFO | 关键业务流程 |
| WARN | 可恢复异常或风险 |
| ERROR | 需要排查的失败 |

## 监控指标

- QPS。
- 错误率。
- P95 / P99 耗时。
- CPU、内存、磁盘。
- 数据库连接池。
- 缓存命中率。
- 消息队列堆积。

## 告警原则

- 告警要能行动。
- 避免无意义噪音。
- 关键业务指标优先于机器指标。
- 告警恢复也要通知。
