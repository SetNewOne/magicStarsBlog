# 限流熔断和降级

限流、熔断和降级用于保护系统，避免局部故障扩散成整体故障。

## 超时

所有外部调用都应该有超时：

- HTTP 客户端超时。
- 数据库查询超时。
- Redis 超时。
- 消息发送超时。

没有超时的调用可能一直占用线程。

## 重试

适合重试：

- 网络抖动。
- 临时超时。
- 读操作或幂等写操作。

不适合盲目重试：

- 支付扣款。
- 创建订单。
- 已经明确失败的业务错误。

## 限流

限流用于控制请求进入系统的速度。

常见维度：

- 按接口。
- 按用户。
- 按 IP。
- 按租户。

## 熔断

当下游服务持续失败时，临时停止调用，快速返回失败或降级结果。

## 降级

降级是在非核心能力失败时提供兜底。

示例：

- 推荐服务失败时返回默认推荐。
- 统计服务失败时隐藏统计模块。
- 第三方头像失败时显示默认头像。
