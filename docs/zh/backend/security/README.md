# 后端安全

后端安全的核心是保护身份、权限、数据和系统边界。任何直接接收外部输入的地方都要有校验和防护。

## 安全目标

- 用户身份可信。
- 权限判断可靠。
- 输入不可破坏系统。
- 敏感数据不泄露。
- 操作可审计。

## 常见风险

- SQL 注入。
- 越权访问。
- 明文密码。
- 文件上传漏洞。
- token 泄露。
- 敏感信息写入日志。
- 依赖库存在已知漏洞。

## 基础清单

- 密码哈希保存。
- 接口统一认证。
- 关键接口做权限判断。
- SQL 使用参数化查询。
- 文件上传限制类型和大小。
- 日志脱敏。
- 生产配置不提交到代码仓库。
