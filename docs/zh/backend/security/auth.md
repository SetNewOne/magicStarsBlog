# 认证和授权

认证确认用户身份，授权确认用户能访问哪些资源。

## 认证方式

| 方式 | 说明 |
|------|------|
| Session | 服务端保存登录态，浏览器保存 Cookie |
| JWT | token 自包含用户信息，适合前后端分离 |
| OAuth2 | 第三方授权登录和授权访问 |

## JWT 注意事项

- 设置过期时间。
- 使用 HTTPS。
- 不在 token 中放敏感信息。
- 服务端要能处理退出登录或封禁场景。
- 前端存储 token 要考虑 XSS 风险。

## 权限模型

```text
用户
  ↓
角色
  ↓
权限点
  ↓
接口 / 菜单 / 数据范围
```

## 越权防护

常见越权：

- 普通用户访问管理员接口。
- 用户通过改 ID 查看别人的订单。
- 只控制菜单显示，没有控制接口权限。

防护建议：

- 接口层必须校验权限。
- 数据查询带上当前用户或租户范围。
- 管理操作记录审计日志。
