# RESTful 规范

RESTful 接口用资源表达业务对象，用 HTTP 方法表达操作。

## HTTP 方法

| 方法 | 用途 |
|------|------|
| GET | 查询 |
| POST | 创建或提交动作 |
| PUT | 全量更新 |
| PATCH | 部分更新 |
| DELETE | 删除 |

## 状态码使用

| 状态码 | 场景 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 204 | 成功但无返回体 |
| 400 | 参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 资源冲突 |
| 500 | 服务端异常 |

## 分页

```text
GET /api/orders?page=1&pageSize=20&status=paid
```

响应示例：

```json
{
  "data": {
    "items": [],
    "page": 1,
    "pageSize": 20,
    "total": 0
  }
}
```

## 幂等性

幂等表示同一个请求执行多次，结果和执行一次一致。

常见处理：

- 删除接口天然接近幂等。
- 支付、下单等接口使用幂等键。
- 重试请求要避免重复写入。
