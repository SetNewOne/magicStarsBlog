# 错误码和文档

错误处理的目标是让调用方知道发生了什么、是否能重试、应该如何修复。

## 错误响应

```json
{
  "code": "USER_NOT_FOUND",
  "message": "用户不存在",
  "traceId": "01HZY..."
}
```

建议：

- `code` 给程序判断。
- `message` 给人阅读。
- `traceId` 用于日志追踪。

## 错误分类

| 类型 | 示例 |
|------|------|
| 参数错误 | 字段为空、格式错误、范围错误 |
| 认证错误 | 未登录、token 过期 |
| 权限错误 | 没有操作权限 |
| 业务错误 | 库存不足、余额不足 |
| 系统错误 | 数据库异常、第三方服务失败 |

## OpenAPI 文档

接口文档应包含：

- 请求路径和方法。
- 请求头。
- 路径参数和查询参数。
- 请求体示例。
- 响应体示例。
- 错误码说明。

文档要跟随代码更新，否则很快失去可信度。
