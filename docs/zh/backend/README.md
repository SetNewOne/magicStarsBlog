# 后端开发知识体系

后端工程师负责把业务规则、数据存储、接口服务、系统稳定性和部署运维连接起来。本模块按一名后端工程师的成长曲线组织：先精通 Java 和 Python，再掌握数据库、Web 框架、缓存、消息队列、测试、安全、部署和系统设计。

版本建议以 2026-05-16 为时间点整理，实际项目应结合团队基础、依赖生态、长期支持周期和安全更新策略选择。

## 能力定位

本博客的后端部分定位为：

- 精通语言：Java、Python 的语法、类型、异常、集合、IO、并发和工程实践。
- 精通服务端开发：接口设计、参数校验、认证授权、事务、日志、异常处理。
- 熟悉主流框架：Spring Boot、Django、FastAPI、Flask。
- 熟悉数据系统：MySQL、Oracle、SQL Server、Redis，能理解 SQL、索引、事务和锁。
- 具备工程能力：构建、测试、配置、部署、监控、性能分析、问题排查。
- 具备架构意识：分层设计、领域建模、缓存策略、异步解耦、系统演进。

## 成长曲线

```text
语言基础
  Java / Python
        ↓
Web 服务
  HTTP、REST API、参数校验、异常处理、认证授权
        ↓
数据能力
  SQL、事务、索引、ORM、缓存、数据库设计
        ↓
工程实践
  构建、测试、日志、配置、部署、CI/CD
        ↓
高并发和稳定性
  线程池、异步任务、消息队列、限流、熔断、监控
        ↓
系统设计
  分层架构、微服务、领域建模、可扩展性、可维护性
```

## 一、Java 技术体系

Java 适合企业级系统、复杂业务后台、微服务、大数据生态和长期维护项目。学习 Java 不能只停留在语法，要理解 JVM、并发、集合、异常、泛型和工程化。

版本选择：

| 版本 | 定位 | 学习建议 |
|------|------|----------|
| Java 8 | 大量旧系统仍在使用 | 维护旧项目需要懂，不建议新项目优先选择 |
| Java 11 | 较老 LTS | 存量系统常见，迁移时需要了解 |
| Java 17 | 现代 Spring 生态的重要基线 | Spring Boot 3.x 最低要求，必须掌握 |
| Java 21 | 成熟 LTS | 新项目常见选择，适合生产 |
| Java 25 | 最新 LTS | 新项目可评估，适合关注长期升级路线的团队 |

Java 核心能力：

- 基础语法：变量、类型、流程控制、方法。
- 面向对象：封装、继承、多态、接口、抽象类。
- 集合框架：List、Set、Map、Queue、迭代器、排序。
- 泛型：类型参数、通配符、边界。
- 异常处理：受检异常、运行时异常、异常链、统一处理。
- IO / NIO：文件、流、缓冲、路径。
- 并发：线程、锁、线程池、原子类、CompletableFuture。
- JVM：内存区域、垃圾回收、类加载、参数调优。
- 新特性：record、switch 表达式、文本块、虚拟线程等。

学习目标：

- 能写出结构清晰、异常明确、类型可靠的 Java 代码。
- 能理解线程安全问题和线程池风险。
- 能阅读 GC 日志和常见 JVM 参数。
- 能把业务逻辑拆到合理的层次中。

## 二、Spring Boot 技术栈

Spring Boot 是 Java 后端最常见的生产框架之一。学习重点不是背注解，而是理解请求进入系统后如何经过控制器、服务、数据访问、事务、异常处理和返回结果。

版本选择：

| 版本 | 定位 | 学习建议 |
|------|------|----------|
| Spring Boot 2.x | 旧项目常见 | 维护存量系统需要懂，注意 Java 8/11 和 `javax` 生态 |
| Spring Boot 3.5.x | 当前稳定生产线之一 | 基于 Spring Framework 6，要求 Java 17+，适合多数企业新项目 |
| Spring Boot 4.0.x | 新一代主线 | 基于 Spring Framework 7，兼容 Java 17，并增强 Java 25 支持；新项目可评估，迁移需谨慎 |

Spring Boot 核心能力：

- Web：Controller、Request、Response、REST API。
- 配置：配置文件、环境变量、多环境配置。
- 校验：参数校验、分组校验、自定义校验。
- 异常：全局异常处理、错误码、统一返回结构。
- 数据访问：Spring Data JPA、MyBatis、事务管理。
- 安全：Spring Security、JWT、OAuth2、权限模型。
- 任务：定时任务、异步任务、线程池。
- 可观测性：日志、指标、健康检查、链路追踪。
- 测试：单元测试、集成测试、MockMvc、Testcontainers。

学习目标：

- 能独立搭建一个规范的 REST API 服务。
- 能处理登录、权限、参数校验、分页、事务和异常。
- 能定位接口慢、事务失效、连接池耗尽等常见问题。

## 三、Python 技术体系

Python 适合 Web 服务、自动化脚本、数据处理、AI 工具链、任务调度和快速业务验证。后端方向学习 Python，要同时重视语言表达力、包管理、异步、类型标注和测试。

版本选择：

| 版本 | 定位 | 学习建议 |
|------|------|----------|
| Python 3.10 | 仍在安全支持期 | 旧项目可能使用，逐步升级 |
| Python 3.11 | 性能提升明显，仍在安全支持期 | 常见生产版本 |
| Python 3.12 | 稳定生产版本 | 新项目可选 |
| Python 3.13 | 当前成熟 bugfix 版本 | 新项目可选 |
| Python 3.14 | 当前最新稳定大版本 | 可评估新特性和依赖兼容性后使用 |

Python 核心能力：

- 基础语法：变量、分支、循环、函数、模块。
- 数据结构：list、tuple、dict、set、dataclass。
- 面向对象：类、继承、协议、魔术方法。
- 函数式能力：推导式、生成器、装饰器、上下文管理器。
- 异常处理：捕获具体异常、异常链、业务异常。
- 类型标注：`typing`、泛型、`mypy` / `pyright`。
- 包管理：venv、pip、uv、依赖锁定。
- 异步：asyncio、任务并发、超时、取消。
- 测试：pytest、fixture、参数化、Mock。

学习目标：

- 能写出清晰、可测试、可复用的 Python 模块。
- 能使用虚拟环境隔离依赖。
- 能处理异步 IO、任务调度和接口服务。
- 能通过类型标注降低大型项目维护成本。

## 四、Python Web 框架

Python 后端框架应按业务场景选择，不同框架解决的问题不同。

版本选择：

| 框架 | 推荐版本线 | 适合场景 |
|------|------------|----------|
| Django | 5.2.x LTS | 管理后台、内容系统、传统业务系统、快速交付 |
| FastAPI | 0.136.x | API 服务、异步接口、类型驱动开发、AI 工具服务 |
| Flask | 3.1.x | 小型服务、内部工具、轻量 API、教学项目 |

Django 核心能力：

- MTV 架构、URL、View、Template。
- ORM、模型关系、迁移。
- Admin 后台。
- 表单、权限、会话。
- 中间件、缓存、国际化。

FastAPI 核心能力：

- 路由、依赖注入、请求和响应模型。
- Pydantic 数据校验。
- OpenAPI 文档自动生成。
- async/await 异步接口。
- SQLAlchemy、任务队列和认证集成。

Flask 核心能力：

- 路由、蓝图、请求上下文。
- Jinja 模板。
- 扩展机制。
- 轻量服务组织方式。

## 五、数据库和数据访问

后端工程师必须理解数据。不会数据库，只会写接口，很难处理真实业务。

重点数据库：

| 数据库 | 推荐版本线 | 说明 |
|--------|------------|------|
| MySQL | 8.4 LTS，旧项目常见 8.0 | Web 业务系统常用 |
| Oracle | 19c / 23ai | 企业级系统常见 |
| SQL Server | 2019 / 2022 | Windows 和企业管理系统常见 |
| Redis | 7.x / 8.x | 缓存、分布式锁、计数、队列辅助 |

核心能力：

- SQL：增删改查、连接、分组、排序、分页。
- 表设计：主键、外键、唯一约束、字段类型。
- 索引：B+Tree、联合索引、最左匹配、覆盖索引。
- 事务：ACID、隔离级别、锁、死锁。
- ORM：JPA、MyBatis、SQLAlchemy、Django ORM。
- 优化：执行计划、慢查询、批量操作、分页优化。

学习目标：

- 能设计清晰的数据表。
- 能写出正确、高效、可维护的 SQL。
- 能解释事务和锁导致的问题。
- 能通过执行计划定位慢查询。

## 六、接口设计和服务规范

接口是前后端协作和服务间协作的契约。

重点能力：

- RESTful 资源设计。
- 请求参数、路径参数、查询参数、请求体。
- 统一响应结构。
- 错误码和错误信息。
- 分页、排序、筛选。
- 幂等性设计。
- 接口版本管理。
- OpenAPI / Swagger 文档。

接口设计示例：

```text
GET    /api/users?page=1&pageSize=20
GET    /api/users/{id}
POST   /api/users
PUT    /api/users/{id}
DELETE /api/users/{id}
```

学习目标：

- 能让接口语义清楚、返回稳定、错误可理解。
- 能减少前后端反复沟通成本。
- 能为后续版本升级留出空间。

## 七、系统稳定性

稳定性不是上线后再补救，而是设计和开发阶段就要考虑。

重点能力：

- 日志：请求日志、业务日志、错误日志、链路 ID。
- 监控：接口耗时、错误率、QPS、资源使用。
- 限流：保护接口和下游服务。
- 熔断和降级：避免故障扩散。
- 重试：只对适合重试的操作重试，避免重复写入。
- 超时：接口、数据库、缓存、第三方请求都要有超时。
- 备份和恢复：数据库备份、回滚方案、数据修复。

学习目标：

- 能定位线上错误来源。
- 能避免单点故障拖垮整个系统。
- 能设计可恢复、可观测、可回滚的服务。

## 八、安全基础

后端直接面对数据和权限，安全是基本功。

重点能力：

- 身份认证：Session、JWT、OAuth2。
- 权限控制：角色、权限点、数据权限。
- 密码安全：哈希、盐、强度校验。
- SQL 注入防护：参数化查询。
- XSS / CSRF 基础。
- 文件上传安全：类型、大小、路径、病毒扫描。
- 敏感信息保护：脱敏、加密、密钥管理。
- 依赖安全：及时升级存在漏洞的库。

学习目标：

- 能避免常见注入和越权问题。
- 能设计基础权限模型。
- 能识别日志、配置和接口中的敏感信息泄露风险。

## 九、测试和工程质量

后端服务要靠测试和工程规范保证长期稳定。

重点能力：

- 单元测试：业务函数、工具函数、边界条件。
- 集成测试：数据库、缓存、接口。
- 契约测试：接口输入输出约定。
- 测试数据：构造、隔离、清理。
- 代码规范：分层、命名、异常、日志。
- CI/CD：构建、测试、镜像、部署。

验收标准：

- 核心业务有测试。
- 修改代码后能快速验证。
- 构建过程可重复。
- 配置和密钥不写死在代码里。

## 十、部署和运维基础

后端工程师至少要理解服务如何运行到生产环境。

重点能力：

- Linux 基础命令。
- 进程、端口、环境变量。
- Docker 镜像和容器。
- Nginx 反向代理。
- 数据库连接池。
- 配置中心和环境隔离。
- 灰度发布、回滚、健康检查。
- 日志采集和监控告警。

学习目标：

- 能把服务从本地运行到服务器或容器环境。
- 能查看日志、端口、进程和资源占用。
- 能判断问题是代码、配置、网络还是依赖服务导致的。

## 阶段性项目

### 初级阶段

- 用户注册登录 API。
- 博客文章 CRUD。
- 文件上传服务。
- 定时任务脚本。

验收标准：接口可用、参数校验完整、异常返回清楚、数据库表设计合理。

### 中级阶段

- Java Spring Boot 管理后台接口。
- Python FastAPI 数据服务。
- Django 内容管理系统。
- Redis 缓存和登录态管理。

验收标准：有认证授权、分页查询、事务处理、日志、测试和部署说明。

### 高级阶段

- 秒杀或高并发下单模型。
- 消息队列异步处理系统。
- 多服务权限系统。
- 可观测的微服务样例。

验收标准：能解释系统瓶颈、故障边界、数据一致性和恢复策略。

## 推荐学习顺序

1. Java 和 Python 至少先精通一门，再熟悉另一门。
2. 学 HTTP、REST API、认证授权和错误处理。
3. 学 SQL、索引、事务、ORM 和数据库设计。
4. Java 方向深入 Spring Boot；Python 方向深入 Django 或 FastAPI。
5. 补齐缓存、消息队列、任务调度、测试和部署。
6. 学系统设计、性能优化、稳定性和安全。
