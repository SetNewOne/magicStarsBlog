# 性能指标

性能指标帮助我们把“感觉慢”转成可测量的问题。

## Core Web Vitals

### LCP

LCP 关注页面中最大的可见内容何时渲染出来。常见对象是大图、标题、首屏主要卡片。

优化方向：

- 压缩首屏图片。
- 避免首屏接口过慢。
- 减少阻塞渲染的 CSS 和 JS。
- 关键资源使用预加载。

### INP

INP 关注用户点击、输入、键盘操作后页面响应是否及时。

优化方向：

- 拆分长任务。
- 减少一次交互触发的大量计算。
- 列表虚拟滚动。
- 避免频繁同步读写 DOM。

### CLS

CLS 关注页面是否发生意外位移。

优化方向：

- 图片和视频设置尺寸或宽高比。
- 字体加载避免明显跳动。
- 广告、弹窗、异步内容预留空间。
- 不在已有内容上方突然插入大块元素。

## DevTools 检查

1. 使用 Lighthouse 获取初步报告。
2. 使用 Performance 录制真实操作。
3. 使用 Network 查看资源体积和加载顺序。
4. 使用 Coverage 查找未使用代码。
