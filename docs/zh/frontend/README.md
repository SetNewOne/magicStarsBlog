# 前端开发知识体系

前端工程师不是只会写页面，而是要把用户界面、浏览器能力、工程化、性能、可访问性和业务交互完整串起来。本模块按一名前端工程师的成长曲线组织：先精通 HTML、CSS、JavaScript，再熟悉主流框架 Vue 和 React，最后进入工程化、质量保障和复杂应用架构。

版本建议以 2026-05-16 为时间点整理，后续学习时应优先查看官方文档的最新支持状态。

## 能力定位

本博客的前端部分定位为：

- 精通基础：HTML、CSS、JavaScript、浏览器、网络、DOM、事件、异步、模块化。
- 熟悉框架：Vue 2.7、Vue 3.5、React 18.3、React 19.2。
- 能做项目：会拆组件、管状态、接接口、做路由、处理权限、优化体验。
- 有工程意识：会使用 TypeScript、Vite、包管理、代码规范、构建发布、测试和性能分析。
- 能持续成长：能从业务页面走向大型应用、组件库、前端架构和跨端方案。

## 成长曲线

```text
基础入门
  HTML / CSS / JavaScript
        ↓
页面开发
  语义化、布局、表单、交互、响应式
        ↓
框架开发
  Vue / React、组件、路由、状态管理
        ↓
工程化开发
  TypeScript、Vite、规范、测试、构建、发布
        ↓
复杂应用
  权限、性能、可访问性、微前端、组件库、监控
        ↓
前端架构
  技术选型、项目规范、稳定性、可维护性、团队协作
```

## 一、HTML：页面结构和语义

HTML 是页面的骨架。真正要掌握的是结构表达能力，而不是只记标签。

重点能力：

- 文档结构：`html`、`head`、`body`、标题层级、页面区域划分。
- 语义化：`header`、`nav`、`main`、`article`、`section`、`aside`、`footer`。
- 表单：输入类型、校验、提交、可访问标签、自动填充。
- 多媒体：图片、音频、视频、懒加载、替代文本。
- SEO：标题、描述、语义结构、规范链接、结构化内容。
- 可访问性：键盘可用、读屏可读、按钮和链接语义正确。

学习目标：

- 能写出结构清楚、语义正确的页面。
- 能让表单在没有复杂脚本的情况下也具备基础校验。
- 能避免把所有内容都写成无意义的 `div`。

## 二、CSS：布局、视觉和响应式

CSS 不是简单“调样式”，它决定页面的布局稳定性、视觉一致性和响应式能力。

重点能力：

- 选择器、继承、层叠、优先级。
- 盒模型、普通流、定位、浮动历史问题。
- Flexbox：一维布局、导航、表单行、工具栏。
- Grid：二维布局、页面骨架、卡片列表。
- 响应式：媒体查询、移动端优先、弹性尺寸。
- 动画：过渡、关键帧、`transform`、`opacity`、减少抖动。
- 可维护性：CSS 变量、命名规范、组件样式隔离。

学习目标：

- 能独立还原常见页面布局。
- 能处理移动端、平板、桌面端的适配。
- 能解释样式为什么没有生效，能定位布局错乱原因。
- 能写出稳定、不抖动、不乱跳的交互样式。

## 三、JavaScript：交互和应用逻辑

JavaScript 是前端应用的核心语言。要从“会写语法”成长为“能组织复杂交互和状态”。

重点能力：

- 基础语法：变量、类型、函数、对象、数组、模块。
- 运行机制：作用域、闭包、原型、`this`、事件循环。
- DOM 和事件：节点查询、事件冒泡、事件委托、表单事件。
- 异步编程：Promise、async/await、并发、错误处理。
- 网络请求：Fetch、状态码、超时、重试、接口错误。
- 数据处理：数组方法、对象转换、日期、国际化格式。
- 浏览器能力：存储、缓存、剪贴板、文件、History、URL。

学习目标：

- 能写出清晰的交互逻辑。
- 能处理接口请求、加载状态、失败状态和空数据状态。
- 能理解异步执行顺序，避免重复请求和状态覆盖。
- 能把复杂逻辑拆成可复用模块。

## 四、TypeScript：大型前端的基础设施

TypeScript 不是为了让代码变复杂，而是为了让项目变大后仍然可维护。

建议版本：

- TypeScript 5.x：当前主流稳定大版本。

重点能力：

- 基础类型、联合类型、字面量类型。
- 接口、类型别名、泛型。
- 类型收窄、类型守卫、工具类型。
- API 数据类型定义。
- Vue / React 组件 props、事件、状态类型。

学习目标：

- 能给接口响应、组件参数、表单数据建立可靠类型。
- 能用类型提前发现低级错误。
- 不滥用 `any`，必要时用 `unknown` 再做类型收窄。

## 五、Vue 技术栈

Vue 在国内业务系统、中后台、低代码平台和渐进式改造项目中使用广泛。学习时要同时理解 Vue 2 和 Vue 3，因为大量旧项目仍在 Vue 2，新增项目更应以 Vue 3 为主。

版本选择：

| 版本 | 定位 | 学习建议 |
|------|------|----------|
| Vue 2.7.x | 旧项目维护版本，Vue 2 最后一个小版本 | 需要掌握 Options API、生命周期、Vuex、旧项目迁移 |
| Vue 3.5.x | 当前主线稳定版本 | 新项目优先，重点学习 Composition API、`script setup`、Pinia |

注意：Vue 2 已在 2023-12-31 结束官方生命周期，继续学习 Vue 2 是为了维护存量项目和理解迁移，不建议新项目继续选 Vue 2。

Vue 核心能力：

- 模板语法：插值、指令、条件渲染、列表渲染。
- 响应式：`ref`、`reactive`、`computed`、`watch`。
- 组件通信：props、emit、slot、provide/inject。
- 路由：Vue Router 4，路由参数、守卫、懒加载。
- 状态管理：Pinia；旧项目常见 Vuex。
- 工程化：Vite、单文件组件、环境变量、构建优化。
- 迁移能力：Vue 2 到 Vue 3、Vuex 到 Pinia、Options API 到 Composition API。

Vue 项目实践：

- 管理后台：菜单、权限、表格、表单、弹窗、文件上传。
- 内容系统：列表、详情、搜索、分页、富文本。
- 数据看板：图表、筛选、实时刷新、性能优化。

## 六、React 技术栈

React 在全球前端生态、复杂 Web 应用、跨端和全栈框架中使用非常广。学习重点是组件、状态、Hooks、不可变数据和渲染模型。

版本选择：

| 版本 | 定位 | 学习建议 |
|------|------|----------|
| React 18.3.x | 旧项目迁移和兼容版本 | 适合理解 React 18 项目、并为 React 19 升级做准备 |
| React 19.2.x | 当前官方文档对应的最新主线 | 新项目可优先学习，注意框架和生态兼容性 |

React 核心能力：

- JSX：用表达式描述界面。
- 组件：函数组件、props、children、组合模式。
- 状态：`useState`、状态提升、不可变更新。
- 副作用：`useEffect`、清理函数、依赖数组。
- 性能：`memo`、`useMemo`、`useCallback`、列表 key。
- 路由：React Router。
- 状态管理：Context、Zustand、Redux Toolkit。
- 服务端数据：TanStack Query、缓存、重试、失效刷新。

React 项目实践：

- 搜索和筛选页面。
- 多步骤表单。
- 权限后台。
- SSR / SSG 应用，可进一步学习 Next.js。

## 七、工程化和工具链

前端工程化的目标是让项目能稳定开发、稳定构建、稳定发布。

版本建议：

| 工具 | 推荐版本线 | 说明 |
|------|------------|------|
| Node.js | 24.x LTS，旧项目可用 22.x LTS | 偶数版本进入 LTS，更适合生产 |
| npm / pnpm | 随 Node 或使用 pnpm 9/10 | 团队内统一即可 |
| Vite | 6.x / 7.x | Vue 和 React 新项目常用 |
| TypeScript | 5.x | 大型项目建议使用 |

重点能力：

- 包管理：依赖安装、锁文件、版本范围、依赖升级。
- 构建工具：开发服务器、生产构建、代码拆分、资源处理。
- 代码规范：ESLint、Prettier、提交规范。
- 环境管理：开发、测试、预发、生产。
- Mock 和联调：接口约定、错误码、数据结构。
- 发布：静态资源部署、缓存策略、回滚。

## 八、浏览器、网络和性能

业务越复杂，越需要理解浏览器底层能力。

重点能力：

- 浏览器渲染：DOM、CSSOM、布局、绘制、合成。
- 网络：HTTP、HTTPS、缓存、Cookie、跨域、状态码。
- 性能指标：LCP、INP、CLS、首屏时间、资源体积。
- 优化手段：懒加载、预加载、代码分割、图片优化、缓存。
- 稳定性：错误捕获、接口监控、白屏排查、日志上报。

学习目标：

- 能定位页面慢在哪里。
- 能解释为什么页面抖动、闪烁、白屏或重复请求。
- 能把性能优化落到具体代码和资源策略上。

## 九、质量保障

成熟前端工程师要能保证修改后的功能不轻易回归。

重点能力：

- 单元测试：Vitest、Jest。
- 组件测试：Vue Test Utils、React Testing Library。
- 端到端测试：Playwright。
- 类型检查：TypeScript。
- 构建验证：生产构建、路由检查、资源检查。
- 可访问性检查：键盘导航、对比度、语义标签。

## 十、阶段性项目

### 初级阶段

- 个人主页。
- 商品列表页。
- Todo 应用。
- 表单提交页。

验收标准：页面结构正确、样式稳定、交互可用、移动端不乱。

### 中级阶段

- Vue 管理后台。
- React 搜索系统。
- 博客前台。
- 文件上传和表单配置页面。

验收标准：组件拆分清楚、接口状态完整、路由和权限可用、构建通过。

### 高级阶段

- 组件库。
- 数据看板。
- 低代码表单设计器。
- 微前端或多应用集成。

验收标准：性能可控、边界状态完整、可测试、可维护、可扩展。

## 推荐学习顺序

1. HTML、CSS、JavaScript 基础先打牢。
2. 学 TypeScript，建立类型意识。
3. Vue 和 React 至少精通一个、熟悉另一个。
4. 补齐路由、状态管理、接口请求、权限和构建。
5. 学测试、性能、可访问性和监控。
6. 通过项目沉淀组件库、规范和架构能力。
