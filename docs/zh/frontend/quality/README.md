# 前端质量保障

质量保障的目标是让功能可验证、改动可回归、页面可访问、问题可追踪。

## 质量维度

- 类型检查：减少低级字段和参数错误。
- 单元测试：验证函数和小模块。
- 组件测试：验证组件状态和交互。
- 端到端测试：验证真实用户流程。
- 可访问性：保证键盘、读屏和语义正确。
- 构建验证：确保生产打包可用。

## 推荐工具

| 工具 | 用途 |
|------|------|
| TypeScript | 类型检查 |
| ESLint | 代码质量 |
| Prettier | 格式化 |
| Vitest | 单元测试 |
| Testing Library | 组件行为测试 |
| Playwright | 浏览器端到端测试 |
| Lighthouse | 性能和可访问性初检 |

## 验收清单

- 正常状态可用。
- 加载状态明确。
- 空数据状态清楚。
- 错误状态可恢复。
- 移动端和桌面端都不乱。
- 关键流程至少有一种自动化或手动验证。
